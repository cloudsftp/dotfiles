# Rust

## Project Setup

Use `cargo` for managing the project.

### Tools

You can use `cargo` to execute tools.

For checking the compilation fast, use `cargo check`
For formatting, use `cargo fmt`
For testing, use `cargo test`
For linting, use `cargo clippy`

After making changes, make sure all the above tools pass.

### Executing

For executing the program, use `cargo run`
